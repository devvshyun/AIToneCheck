AI 톤 체크

한국어 글에서 AI가 쓴 것처럼 읽히는 부분을 찾아 표시하고, 고칠 방향을 알려 줍니다. 무엇을 고칠지는 직접 고릅니다.

글 넣기↓
01

글 입력

소설, 에세이, 칼럼을 붙여 넣으세요. 따옴표로 시작하는 줄은 대사로 보고 서술과 따로 셉니다. 입력한 글은 이 브라우저에서만 처리됩니다.

예문
0
02

결과

AI가 썼는지 판별하는 값은 아닙니다. 의심 표현이 글에 얼마나 몰려 있는지 보여 줍니다.

    03

    문장 리듬

    대사를 뺀 서술 문장만 셉니다. 합격선은 없고 참고용으로 보는 숫자입니다.

    04

    표시된 문장

    실선 강함 물결 중간 점선 약함

    항목

      05

      고친 안

      단어를 지우거나 바꾸는 정도로 고칠 수 있는 곳만 제안합니다. 기본값은 원문 유지이고, 적용할 것만 고르면 됩니다.

        원문

        수정본 직접 고쳐도 됩니다

        06

        다시 검사

        표현 하나를 지우면 다른 상투 표현이 그 자리에 들어가기 쉽습니다. 수정본을 같은 기준으로 다시 검사한 결과입니다.

        07

        직접 확인할 것

        자동으로는 찾기 어려운 항목입니다. 글을 읽으면서 확인하세요.

          LLM에게 맡기기

          이 페이지는 LLM을 호출하지 않습니다. 더 자세한 피드백이 필요하면 아래 프롬프트를 복사해 Claude 같은 챗봇에 붙여 넣으세요. 입력한 글, 검사 결과, 검사 기준이 함께 들어 있습니다.

          1. 1
            숫자는 참고용입니다. 어디부터 읽을지 고르는 데 쓰고, 고칠지는 글을 읽고 판단합니다. 숫자를 낮추려고 고치면 글이 오히려 어색해집니다.
            2. 
        
          2. 2
            한 번 나온 표현은 대체로 괜찮습니다. 같은 표현이 반복되거나 한곳에 몰렸을 때 무겁게 봅니다.
            3. 
        
          3. 3
            고친 뒤에 다시 검사합니다. 설명 문장을 지우면 '한참'이 늘고, 짧은 문장을 이으면 같은 연결어미가 늘어나는 식으로 다른 문제가 생기기 쉽습니다.
            4. 
        
          4. 4
            문장 길이가 고르면 의심합니다. 짧은 문장만 이어지거나 긴 문장만 이어지는 글이 기계적으로 읽힙니다.
